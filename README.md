# mytool

`mytool` 是一个用于沉淀常用工具能力的项目。当前仓库处于初始化阶段，后续可以根据实际需求扩展为命令行工具、脚本集合或可复用工具库。

## 项目目标

- 收集并封装日常开发中高频使用的工具方法
- 降低重复脚本编写成本
- 提供清晰、可维护、可扩展的项目结构
- 方便后续通过命令行、模块引用或自动化流程复用
